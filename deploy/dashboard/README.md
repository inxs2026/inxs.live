# Racing calendar status

These backend files mirror the installed Dashboard service on Linux, port 8088.
Frontend source lives in web/. No picks are generated by this status check.

woodbine-calendar.json transcribes the 128 approved 2026 Woodbine Thoroughbred dates, AGCO calendar as of March 17, 2026. Source URL is included in the JSON and racing page. Refresh it against official calendar revisions before each season, updating year, dates, source and asOf together and the expected date count validation in race_schedule.py. Unknown years or missing/invalid calendars remain unknown, never off-days. Saved card evidence overrides a conflicting off-day entry.

Validation: python3 -m unittest test_racing test_race_schedule in the live Dashboard directory; npm test in INXS-Live.
