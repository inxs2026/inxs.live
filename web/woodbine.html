How the comparison and $2 simulation work

Both agents are measured on the same completed races. Saved files must predate post time, and each original top-three horse must match its program number and name. A scratched first pick is excluded for both agents, with no promotion. Hypothetical returns use a $2 CAD win wager on the original first pick and the source-reported Win payout, including stake. Missing winning payouts exclude that race from both agents’ return calculations. Win-rate races and wager races are shown separately. Historical files saved after post time cannot establish a pre-race prediction and are excluded. Results are reported by TrackData / Equibase; this is a hypothetical record, with no wagers placed.
